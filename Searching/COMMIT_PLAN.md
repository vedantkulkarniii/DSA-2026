---

## Commit Convention Used

```
<Topic> #<Number>: <Action> <Description> | <Complexity>
```

- **Topic**       : The DSA topic (e.g., Searching, Arrays, Strings)
- **Number**      : Problem number within the topic
- **Action**      : Verb — Implement / Find / Add / Solve
- **Description** : Short problem description
- **Complexity**  : Time and Space complexity

---

## Why One Commit Per Problem?

- Creates a visible contribution history on GitHub
- Shows consistent, structured daily practice
- Makes it easy to track individual problem solutions
- Demonstrates professionalism and discipline to recruiters
